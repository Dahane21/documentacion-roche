# Roche V2.2.11 Web

## Actualización visual Tradel Service
- Se adopta una identidad visual alineada con las aplicaciones internas de Tradel Service: barra superior roja, menú lateral oscuro y rojo institucional como color de acción.
- El menú lateral se reorganiza visualmente en OPERACIÓN, ANÁLISIS y DATOS, sin cambiar rutas ni funcionalidades.
- Se actualizan botones, formularios, tablas, filtros tipo Excel, tarjetas, estados, modales y pantalla de inicio de sesión.
- El logo Tradel pasa a tener mayor presencia en el encabezado lateral.
- Se conserva íntegramente la lógica de Roche V2.2.10: filtros, historial, regularización histórica, reportes, Supabase, respaldos e importación.

## Compatibilidad
- No requiere SQL nuevo.
- No modifica tablas ni estructura de Supabase.
- Caché de recursos actualizada a `v2211`.
