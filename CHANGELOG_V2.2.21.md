# Roche V2.2.21 Web

## Ventana de lote más simple
Rediseñada a partir de lo que hace fácil el Registro rápido (botones y tarjetas grandes de un toque):

1. **¿Qué guías llegaron?** Cada guía tiene una casilla grande "LLEGÓ" (verde cuando está marcada) y el botón "Llegaron todas".
2. **Tipo de cada guía con botones de un toque**, siempre visibles en su fila (no hay listas desplegables). Sirve para GRT con tipos mezclados, por ejemplo 1 suministro y 2 ventas. Las ventas que detecta SUNAT vienen marcadas.
   - Atajo opcional arriba: un toque pone el mismo tipo a todas las que llegaron, sin tocar las ventas detectadas por SUNAT.
3. **Debajo de cada guía, solo lo que su tipo necesita:**
   - Venta / Venta CENARES: casillas "Factura llegó" y "OC llegó".
   - Venta CENARES: contadores − 0 + para GR, actas y pecosas.
   - Todas: casilla "Plantilla". "+ otro documento" abre el campo de texto solo si se necesita.
- "Quitar del lote" pasa a ser una ✕ discreta. "Continuar después", "Saltar" y "Descartar lote" quedan como botones pequeños; "Guardar" es el principal.
- Si falta el tipo de una guía, la ventana la señala en rojo.
- Caché actualizada a `v22210`.
