# Roche V2.2.7 Web

Fecha: 27/09/2026

## Mejoras
- Pendientes / Parciales: filtros tipo Excel desde los encabezados de la tabla, con búsqueda, selección múltiple, selección total y resaltado visual de columnas filtradas.
- Se mantienen arriba los filtros rápidos de GRT/GR/Pedido, Destinatario, Resultado y Docs por enviar.
- El botón Limpiar muestra la cantidad de filtros activos y borra tanto filtros rápidos como filtros de encabezado.
- Los filtros de Pendientes se conservan mientras la página permanezca abierta y no se recargue.
- Listos para enviar: nuevo buscador combinado GRT / GR / Pedido con coincidencia parcial.
- Historial > Contenido del cargo: nuevo buscador combinado GRT / GR / Pedido.
- Liquidados: nuevo buscador combinado GRT / GR / Pedido.
- Actualización visual de versión a V2.2.7 Web.

## Base de datos
No requiere SQL nuevo ni cambios de tablas en Supabase.
